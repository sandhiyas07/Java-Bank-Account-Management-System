# Java Bank Account Management System

A beginner-friendly Java console application for managing basic bank account operations using Object-Oriented Programming (OOP).

## Project Overview

The Bank Account Management System is a simple Java application that allows users to check their account balance, deposit money, withdraw money, and view transaction history through a menu-driven console interface.

This project was developed to practice Java fundamentals, classes, objects, methods, loops, and conditional statements.

## Features

- **Check Balance:** View the current account balance.
- **Deposit Money:** Add money to the account.
- **Withdraw Money:** Withdraw money if sufficient balance is available.
- **Transaction History:** View recorded deposits and withdrawals.
- **Input Validation:** Reject negative or invalid transaction amounts.
- **Menu-Driven Interface:** Select operations using numbered menu options.
- **Insufficient Balance Check:** Prevent withdrawals exceeding the available balance.

## Technologies Used

- Object-Oriented Programming (OOP)

## How to Run the Project

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder

```bash
cd Java-Bank-Account-Management-System
```

### Step 3: Compile the Java File

```bash
javac BankAccountManagement.java
```

### Step 4: Run the Application

```bash
java BankAccountManagement
```
